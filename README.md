## Profile maintenance

This is a concise public product overview rather than a source of truth for compatibility, security verification, or production deployment status. Update the [main project README](https://github.com/The-peephole/peephole#readme) first whenever product support changes.

Keep supported static previews separate from the narrower full-stack contract, and describe unsupported repositories as **analysis-only**. The demo GIF linked from the project repository shows a **static** preview, not a full-stack preview.

The banner uses inline vector elements and no external fonts, scripts, images, or network resources.
